# Гидеон 9 — новые реплики

Распакуй ZIP целиком и открой `index.html`. Все шесть фраз можно послушать подряд либо по отдельности. MP3 находятся в папке `audio`; WAV — исходники для дальнейшей работы.

Ты выбрал вариант **«Гидеон 9»**. Его исходный синтетический WAV сохранён в `reference` и используется как эталон для продолжения голоса через **Qwen3-TTS Base**. Исходный образец также доступен на странице для сравнения.

Это новые пробы озвучки. Они не добавляют события в канон и пока не встроены в игру. Тембр новых реплик можно сравнить с исходником на слух.

Модель **Qwen/Qwen3-TTS-12Hz-1.7B-Base** распространяется по лицензии **Apache 2.0**. Локальная генерация не требует подписки или оплаты за символы; нужен компьютер с достаточными ресурсами. Электричество и аренда вычислений, если они используются, могут стоить денег. Текст лицензии Qwen сохранён без изменений в `LICENSE-QWEN.txt`.
