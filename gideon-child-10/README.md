# Гидеон — 10 проб голоса

Распакуй архив целиком и открой `index.html` в браузере. Можно также слушать отдельные MP3 из папки `audio`. Напиши номер понравившегося варианта: «Гидеон 1» — «Гидеон 10».

Направление этих проб — детский мальчишеский голос. Описания обозначают замысел варианта; подходящий тембр выбирается на слух. Все варианты синтетические, созданы по текстовым описаниям, без клонирования голоса актёра.

Общая реплика:

> Привет. Меня зовут Гидеон. Я вижу. Она довольно большая. Нет, я не испугался. Я просто проверяю, где выход.

## Файлы

- `audio/gideon_1.mp3` — `audio/gideon_10.mp3`: удобные копии для прослушивания.
- `audio/gideon_1.wav` — `audio/gideon_10.wav`: исходные записи модели для дальнейшей работы.
- `manifest.json`: фактические параметры генерации и сведения об образцах.
- `LICENSE-QWEN.txt`: исходный текст лицензии Apache 2.0 для Qwen3-TTS.
- `SOURCES.md`: официальные источники о модели, лицензии и повторном использовании выбранного голоса.

В этих пробах не применялись эффекты повышения тона, изменения формант или скорости речи. MP3 — только кодированная копия исходного WAV.

## Бесплатная озвучка будущих глав

Используется локальная модель **Qwen3-TTS-12Hz-1.7B-VoiceDesign** с лицензией **Apache 2.0**. При локальном запуске нет подписки, платы за символы или сервисной квоты. Нужен компьютер с достаточными ресурсами; электричество и аренда вычислений, если они используются, могут стоить денег. Платный облачный API для этого способа не требуется.

Сохрани выбранный WAV, точный текст реплики и `manifest.json`. Разработчики Qwen описывают способ: создать синтетический голос в VoiceDesign, затем использовать эту запись и её текст в **Qwen3-TTS Base** как эталон для новых реплик. Это позволяет работать над одним персонажем в следующих главах. В рамках этих десяти проб продолжение голоса через Base ещё не проверялось; простое повторение описания и seed не гарантирует один и тот же тембр.

Лицензия Apache 2.0 относится к модели и коду. Она не даёт исключительных прав на сгенерированный тембр. Эти образцы пока служат для выбора; в игру они не встроены.
