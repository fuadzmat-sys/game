# Chapter 2 sound assets

Seven environmental Foley clips are original deterministic DSP, generated by
`tools/build-chapter2-audio.py`. They contain no voice recordings.

Four Russian spoken lures are independent fictional Qwen3-TTS VoiceDesign
outputs. No original-game recordings, reference voice, actor identity, speaker
embedding or voice-cloning API was used. Raw float WAVs preserve generated
waveforms; MP3 files are listening/game copies, without pitch or tempo changes.
Prompts, seeds, immutable model revision, hashes and actual ASR results are in
`mimic-voice-provenance.json` and `mimic-asr-review.json`.

These are **generated draft cues**, not approved final character voices. Three
cues match normalized ASR words; the longer Pacifica lure's fictional name is
recognized as «Гидион» instead of «Гидеон», so proper-name pronunciation and
performance should be reviewed by a listener. ASR does not prove naturalness or
age. English spoken lures and the full Chapter 2 dialogue dub are pending.

Lures play once as chapter-specific diegetic effects on the SFX channel, separate
from ordinary dialogue speech. Russian speech cues are suppressed when the
active language is English. Missing dialogue slots remain silent and never fall
back to chapter-zero clips or system TTS.
