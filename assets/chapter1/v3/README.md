# Art for «Следы в лесу» / Tracks in the Forest

These seven PNGs were generated for the new Chapter 1 on 2026-10-28. They are separate from the original Chapter 0 files. No original background, sprite, or resource manifest was changed.

- `yard.png` — morning yard, empty doghouse, outward-broken fence; 1672 × 941.
- `clearing.png` — shaded clearing with collar, torn rope, sack, old bones, and scratched tree; 1672 × 941.
- `road-late-afternoon.png` — old forest road in low afternoon sunlight; 1672 × 941.
- `dog.png` — small dirty ordinary dog from the false alarm; 1536 × 1024, transparent RGBA.
- `buster-collar.png` — intact unfastened collar with the BUSTER nameplate; 1536 × 1024, transparent RGBA.
- `cloth-scrap.png` — dark frayed fabric clue; 1536 × 1024, transparent RGBA.
- `will-observer.png` — provisional mysterious observer illustration; 1086 × 1448, transparent RGBA.

The new illustrations use drawn contours, textured colors, muted woodland palettes, and open staging areas suitable for the existing visual novel characters. No people, plot-revealing monsters, symbols, or magical explanations were added to the backgrounds.

The asset registry in `assets/chapter1-art.json` also reuses the original diner exterior and `forest_1`, `forest_5`, `forest_2` backgrounds. The existing cafe interior remains usable. The three former Chapter 1 monster drawings remain only as illustrations displayed from Journal #3; the monsters are not added as characters in this chapter. The journal itself uses the original `Journal_3.png`.

The superseded dressing room, battle clearing, old cafe interior, and old replacement Will drawing were removed after checking that no original Chapter 0 resources referenced them. The new chapter uses a separate transparent observer illustration of Will.

For the last observer shot, `sprites.will` uses `will-observer.png` (new transparent illustration, 1086 × 1448). It retains the original blue triangle, black top hat and thin limbs, with the face in shadow and a small blue spark. The original tiny `Sad.png` contains a rectangular backing and was unsuitable for enlargement. This replacement is a temporary illustrated staging asset awaiting final art-direction review; the script darkens it. Chapter 0 keeps its original rendering unchanged.
