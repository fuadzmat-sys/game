## NEW UI

В карте решений доступны «Сохранить путь / Export Save» и «Import Save».
Экспорт скачивает `reverse_falls_canon_save.json`. Импорт открывает выбор JSON,
проверяет его, затем показывает подтверждение с кнопками «Отмена» и «Загрузить».
Ошибки выводятся в интерфейсе без замены текущего пути.

Переключатель «Показать спойлеры» удалён. По умолчанию включён «Полный режим»;
сохранены «Мой путь» и «Вся схема». После вкладок глав добавлена «Настоящая история».
В новой вкладке скрыты действия альтернативы/смены пути и неканонические легенды.

Если подтверждена смена ещё не пройденного решения, сохраняется реальная точка
выбранной сцены. Уже выбранные ранние решения используются повторно. Неотвеченные
ранние решения, необходимые для входа, получают первые варианты: об этом прямо
предупреждает окно подтверждения. Временный просмотр никогда не делает этого
с официальным каноном.

## EXPORT FORMAT

Файл содержит `format: "reverse-falls-canon-save"`, `saveFormatVersion: 1`,
`schemaVersion: 1`, `gameVersion: "3.1.0"`, `exportedAt`, `canon`, `snapshots`.

`canon` включает `schemaVersion`, `currentChapter`, `choices`, `progress`,
`derived`. В `derived` находятся флаги/счётчики, отношения с источниками
модификаторов, предметы/улики, знания персонажей и состояния заданий.
`snapshots` — необязательный проверяемый кэш точного продолжения сцен.
Discovery, временная сессия, журнал и резервные копии не экспортируются.

Экспорт читает `storyState.getState()`, а не текущую временную сессию или
движок альтернативы. Vampire остаётся Vampire в JSON во время просмотра
Werewolf. После подтверждённой смены пути экспорт читает новый канон.

## IMPORT: VALIDATION, MIGRATION, CHECKPOINT, ROLLBACK

`previewImport()` не пишет данные. `importSave()` повторно разбирает исходный
выбранный файл, проверяет формат, версии, выборы/варианты, требования,
взаимоисключающие эффекты, источники, прогресс и кэш сцен. Перед импортом
производные эффекты строго сравниваются с результатом реестра — поддельные
источники и несогласованные суммы не исправляются молча.

Миграции portable-формата задаются явно в `portableMigrations`, переходами по
одной версии; схема использует существующий механизм `migrations` сервиса.
Неизвестные версии и отсутствующие переходы отклоняются. Сейчас поставляется
portable v1; старые браузерные сохранения проходят прежнюю миграцию.

После подготовки сцен и финальной проверки существующий механизм сохраняет
checkpoint старого состояния и выполняет одну авторитетную запись нового
состояния. Ошибка подготовки, проверки или записи не заменяет старый канон.
При отказе основной записи контрольная точка уже может быть сохранена.
`storyState.rollback()` поддерживает возврат к прежнему состоянию.

Импорт сохраняет локальные открытия Discovery. Альтернативная сессия удаляется
только после успешного commit. Затем обновляются текущая сцена, «Мой путь»,
проекции кампании и объединённая карта; отдельного сохранения для карты нет.
Ограничение файла в интерфейсе — 16 МиБ. Отсутствующие resume-кэши восстанавливаются
по каноническим решениям и проверяются до commit.

## DECISION MAP

Все узлы уже реализованных глав 0 и 1 показываются сразу, включая непройденные
варианты. Discovery продолжает хранить статистику увиденного, но не управляет
видимостью и не даёт канонических эффектов. Обычный клик показывает сведения.
В «Полном режиме» явные действия запускают временный просмотр либо отдельное
подтверждение транзакционной смены пути.

Графы будущих глав, mock-глава и будущие последствия в рабочую карту не добавлены.

## TRUE STORY

`buildCanonTimeline(storyState.getCanon())` строит линию из зарегистрированных
графов, требований стабильных выборов и официального прогресса. История заканчивается
на достигнутой сцене. Учитывается порядок городских посещений; повторные входы
в городской узел получают уникальные ID. Между главами создаются соединяющие рёбра.
Если глава 1 начата отдельно, отсутствующее прохождение главы 0 не выдумывается.

Проекция не читает Discovery, альтернативу, экспортированный JSON или историю
движка. У неё нет собственного persistent state. Клик только показывает сведения;
вызовы preview/rewrite недоступны. Используется голубое оформление канона.

Для будущей реализованной главы регистрируются граф, entry/exit, сцены и требования
в `CANON_TIMELINE_CHAPTERS`. Обход и отображение не содержат ветвления по главам
0/1. Mock Chapter 2 проверяет расширение и соединение без изменения рендерера;
он существует только в тесте. После rewrite/import проекция строится заново.

## CANON SAFETY

StoryState остаётся единственным источником официальной истории. Все три
представления — экспорт, «Мой путь» и «Настоящая история» — читают его канон.
Временные предметы, отношения и флаги не публикуются при просмотре альтернативы,
выходе, обычном Save или экспорте. Discovery не назначает канон. Импорт — явная
подтверждённая замена; rewrite — отдельная подтверждённая транзакция.

Экспортированный JSON полезен будущей Codex-сессии как снимок официального пути
на дату экспорта. Он не загружается автоматически и не становится вторым runtime
хранилищем. После нового прохождения или смены решений нужно экспортировать его снова.
Пользовательский канонический JSON в исходных вложениях отсутствовал; вымышленный
личный путь в поставляемый проект не добавлен.

все браузерные проверки. Сюжетный движок и сборщик менять не потребовалось.

## KNOWN LIMITATIONS

Проверен Chromium/Linux. Safari/Firefox, запуск через `file://`/START.bat на Windows,
мобильные жесты и полный аудит доступности вручную не проверялись. Озвучка главы 1

нет. Снимок окружения не публиковался; изменения не отправлялись в GitHub.
