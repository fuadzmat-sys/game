Статус: описания и шесть точных реплик новой главы подготовлены; **аудиопробы ещё не созданы**. После публикации среды API Hugging Face стал доступен. Проверены официальные метаданные: revision `5ecdb67327fd37bb2e042aab12ff7391903235d3`, лицензия весов `apache-2.0`, общий размер весов 4 515 695 644 байта. Конфигурации и данные текстового токенизатора скачаны.

Сами веса выдаются с `us.aws.cdn.hf.co`; текущая сеть отклонила этот CDN (`CONNECT 403`). Подготовлен новый черновик, добавляющий только этот адрес к уже разрешённым. Инструмент конфигурации вернул `requires_publish: true`: правило нужно проверить, сохранить и опубликовать через настройки среды. Загрузка возобновляется после применения правила. Остальные настройки сохранены.

Цель — самостоятельные голоса вымышленных персонажей, подходящие по возрасту и манере, без копирования голосов оригинальных исполнителей. Записи из архива игры не используются ни как вход, ни для обучения или референса. Гидеон — спокойный мальчик 12 лет с сухим сарказмом; Пасифика — уверенная и выразительная девочка 14 лет. Это направления для модели; соответствие и качество нужно оценить по реальным пробам.

## Подготовленные файлы

- `tools/independent-voice-probes.json`: два словесных описания, постоянные seed и три точные реплики каждого героя. Идентификаторы и строки совпадают с `assets/chapter1-voice-plan.json`.
- `tools/download-independent-voice-model.py`: доступ к официальному репозиторию Qwen, проверка метаданных лицензии и загрузка зафиксированного снимка вместе с speech tokenizer. Сохраняет подтверждение источника и revision. Веса остаются вне игры.
- `tools/render-independent-voices.py`: только локальный Qwen3-TTS VoiceDesign, без входных голосовых записей и вызова API клонирования. Создаёт WAV и MP3 с текстами и происхождением; все результаты имеют статус непрослушанных проб.
- `tools/independent-voice-requirements.txt`: версии среды генерации.
- `tests/independent_voice_probes_test.py`: проверки соответствия канону, исходным строкам и отсутствия входных голосовых записей. Это проверки инструментов, а не качества речи.
- `tools/build-voice-preview.mjs`: автономная страница с двумя плеерами и текстами. Она создаётся только после появления настоящих файлов; внешние запросы и автозапуск не используются. Четыре проверки упаковки — `tests/voice-preview.test.mjs`.

## Модель и ограничения

Выбран официальный `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`, который поддерживает русский язык и создание голоса по словесному описанию. Рассмотрен исходный код [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS), revision `022e286b98fbec7e1e916cb940cdf532cd9f488e`. Лицензия кода — Apache-2.0. Лицензия весов отдельно подтверждена через официальную карточку модели: apache-2.0; загрузчик фиксирует её вместе с immutable revision.

В текущей среде уже установлен отдельный CPU runtime в `/workspace/independent-voice-tools`: `torch/torchaudio 2.9.1+cpu`, `qwen-tts 0.1.1`, `transformers 4.57.3`, `accelerate 1.12.0`. Импорт проверен. GPU и FlashAttention не требуются для этого варианта; скорость и качество реального синтеза ещё не проверены, поскольку CDN весов пока недоступен. Предупреждение SoX возникает при импорте общего пакета; по проверенному коду SoX вызывается в другом, 25Hz-пути, а выбранный 12Hz VoiceDesign его не использует. Это не заменяет будущую проверку реального синтеза.

## Продолжение после применения сети

```bash
cd /workspace/Projects/reverse-falls
/workspace/independent-voice-tools/bin/python tools/download-independent-voice-model.py
/workspace/independent-voice-tools/bin/python tools/download-independent-voice-model.py --download
/workspace/independent-voice-tools/bin/python tools/render-independent-voices.py \
  --plan tools/independent-voice-probes.json \
  --model /workspace/voice-models/qwen3-tts-independent-design \
  --output /workspace/artifacts/independent-voice-probes
```

Генератор работает на CPU в float32 с eager attention и четырьмя потоками. Сгенерированная волна сохраняется без изменения высоты, темпа и нормализации. MP3 — копия для прослушивания. Время генерации и хеши сохраняются в `preview-index.json`. После реального синтеза собрать страницу прослушивания можно так:

```bash
node tools/build-voice-preview.mjs \
  --input /workspace/artifacts/independent-voice-probes/preview-index.json \
  --output /workspace/artifacts/independent-voice-probes/voice-previews
```

Для проверки плана без модели и зависимостей:

```bash
python3 tools/render-independent-voices.py --validate-only \
  --plan tools/independent-voice-probes.json \
  --output /workspace/artifacts/independent-voice-probes
python3 tests/independent_voice_probes_test.py
```

После генерации нужно прослушать речь на естественность, возраст, дикцию, сарказм и отсутствие странных пауз. Сам факт, что нейросеть вернула WAV, не означает, что качество подходит для игры. Эти пробы не включают переключатель озвучки автоматически и не заменяют полноценный проверенный пакет главы.

Для последующей полной озвучки нужны постоянные самостоятельные тембры всех присутствующих персонажей и записи каждого контекстного слота. Одно короткое «Да» может звучать по-разному в разных сценах. Пакет должен связываться с идентификаторами новой главы, поддерживать паузу/отмену/громкость/авто и не переходить на старые MP3 или Web Speech при отсутствии записи. Сценарий и сохранения главы 0 эта подготовка не меняет.
