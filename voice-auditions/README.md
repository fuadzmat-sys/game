# Reverse Falls — выбор голосов

36 персонажей/ролей, 108 коротких синтетических образцов.
Это экспериментальные пробы для выбора. Озвучка не включена в игру.

## Прослушивание

Распакуйте всю папку и откройте `index.html` в браузере. Для каждого персонажа
есть варианты 1, 2 и 3; звучит только одна запись одновременно. Поиск работает
по русскому имени и внутреннему ID. MP3 можно скачать отдельно.

«Выбрать» отмечает понравившийся вариант и сохраняет отметку только в локальном
хранилище этой страницы: `reverse-falls-voice-audition-choices-v1`.
Ключи сохранений и канон игры не читаются и не изменяются.

«Скачать мой выбор» создаёт `reverse_falls_voice_choices.json`. Можно передать
этот файл или просто написать, например: «Гидеон 2, Венди 1, Мейбл 3».
Необязательно выбирать всех сразу. Сам JSON не включает озвучку в игру.

## Что означают варианты

Это синтетические пробы на четырёх базовых моделях, с настройками тембра,
высоты и темпа. Три женских варианта используют разные обработки одного
базового голоса Ирины; это не три актрисы и не подтверждение финального качества.
Точные модели и параметры каждой записи указаны в `manifest.json`.

У записей статус `unreviewed_auditions`, `integratedIntoGame: false`.
Возраст и естественность звучания нужно оценить по самим образцам. Основная
игра, её сюжет, озвучка и сохранения этими пробами не заменяются.
