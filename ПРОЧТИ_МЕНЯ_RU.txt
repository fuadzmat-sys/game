РЕВЕРС ФОЛЗ — ГЛАВЫ 0–3, РУССКАЯ ВЕРСИЯ

Полностью распакуйте архив. Для запуска откройте START.bat (Windows) или index.html.
Не запускайте игру из окна архиватора.
Для прежних браузерных сохранений используйте тот же браузер и адрес игры.
При переносе в другую папку/на другой компьютер используйте «Карта решений» →
«Сохранить путь», затем «Загрузить путь» в новой копии.

Игроку доступен только русский язык. Выбор языка удалён. Старые сохранения
на других языках принимаются; при продолжении сцена восстанавливается
существующим механизмом воспроизведения на русском с теми же решениями.
Сцена может возобновиться с соответствующей контрольной позиции: номера строк
в старых переводах отличаются.

Исходная архитектура, идентификаторы, флаги, формат сохранений, последствия,
карта ветвлений и сценарий главы 3 сохранены. Старые языковые ресурсы внутри
исходных данных оставлены исключительно для проверки/восстановления прежних
сохранений. Они не предлагаются игроку. Имена авторов и их псевдонимы сохранены.
Английские записи из assets/voices/english удалены. Старые английские короткие
голосовые вставки оригинала отключены. Музыка и игровые звуки сохранены.
Полная озвучка новых глав остаётся в прежнем состоянии готовности.
Одна ошибочная украинская запись главы 0 исключена; для её русского текста
используется существующий механизм озвучки браузером, если он доступен.

Сборка: npm run build
Тесты логики: npm test
Браузерные тесты: npm run test:browser (нужны Playwright и Chromium;
игра должна быть доступна на http://127.0.0.1:8780).
