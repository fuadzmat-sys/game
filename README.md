# Reverse Falls — Chapters 0 & 1

Браузерное воссоздание главы 0 по предоставленной пользователем сборке Unity 2019.2.20f1. Оригинальные диалоги, переводы, спрайты, фоны, шрифты, музыка и звуки извлечены из этой сборки. Логика сценария заново реализована на JavaScript. Код игры загружает изображения, музыку и звук локально. Глава 1 полностью заменена на «Следы в лесу» по новой библии и полному сценарию пользователя. Новая глава временно без финальной озвучки: прежние синтетические реплики главы 1 удалены, браузерное чтение в ней отключено.

## Запуск

Распакуй **весь** архив в одну папку. Открой `index.html` в современном браузере или дважды нажми `START.bat` в Windows. Не перемещай HTML отдельно от остальных файлов. Если браузер ограничивает запуск локальных файлов, установи Python 3 и выполни `python serve.py` в этой папке. Откроется локальная игра; сервер останавливается сочетанием Ctrl+C.

Собранная версия уже включена: Node.js и сборка для игры не нужны. Прямое открытие локального HTML технически подготовлено, но в управляемом браузере среды оно запрещено политикой администратора. Здесь игра проверена через локальный HTTP-сервер.


## Глава 1 — «Следы в лесу»

В меню нажми **«Главы»** и выбери главу 1. История начинается следующим утром после канонической главы 0: Пасифика и Гидеон встречаются у кафе и начинают первое расследование. Пропавшие животные, повреждённый забор, противоречивые следы, ошейник BUSTER и ложная тревога заставляют их проверять догадки. Дневник №3 помогает, но не даёт готового ответа. Уилл остаётся загадочным наблюдателем в финале; объяснение происходящего не раскрывается.

Включены **все 11 сцен полного сценария, четыре выбора по три варианта и три вариации улик по существу из главы 0**. Все русские реплики и повествовательные абзацы сохранены; есть полный английский перевод. 37 сценарных ресурсов на каждом языке содержат основные сцены и локальные ветки. Ветки сходятся после своих последствий, а решения сохраняют открытость Гидеона, доверие друзей, отношение к Дневнику, осторожность и найденные улики. Подробности со спойлерами — [CHAPTER1.md](CHAPTER1.md).

Пасифике 14 лет, Гидеону 12, Мейбл и Дипперу по 15, Венди 18. Пасифика смелая и импульсивная; Гидеон спокойный, саркастичный и наблюдательный. Они равноправные главные герои, между ними нет романтики. Мейбл и Диппер не появляются в новом сюжете главы 1. Основной канон хранится без изменений в [библии сюжета](docs/story-bible.md); точный текст этой главы — в [ТЗ](docs/CHAPTER1_REWRITE.md). Библия имеет высший приоритет.

Выбранный в главе 0 оборотень, вендиго или вампир переносится из завершённого прохождения либо ручного сохранения. При отдельном запуске главы его можно выбрать в меню. Существо пока остаётся рабочей гипотезой: оно меняет страницы Дневника и улики в трёх местах, но в этой главе на героев не нападает настоящий монстр.

Использованы исходные спрайты и выражения лиц Пасифики и Гидеона, исходные городские и лесные фоны, музыка и интерфейс. Для финального кадра Уилла подготовлен отдельный прозрачный силуэт; это временная иллюстрация до окончательной художественной проверки. Сохранён подходящий рисунок кафе. Для отсутствовавших локаций и предметов добавлены изображения двора, поляны, поздней лесной дороги, собаки, ткани и ошейника. Новые эффекты дают птиц, ветер, хруст веток, скуление, неизвестный зов и синюю искру. Синее свечение и состояние предметов сохраняются при загрузке.

**Финальная озвучка новой главы 1 пока не готова.** Старые реплики главы 1 не воспроизводятся; Web Speech и прежние короткие голосовые вставки в ней не используются. Музыка и SFX работают. Подготовлены слоты для будущих актёрских записей с требованиями к возрасту, характеру и интонации. Голоса реальных актёров не клонировались. Озвучка и исходные звуки главы 0 остаются доступными через прежние настройки.

Основная история хранится в `reverse-falls-canon-story-v1`: выборы, прогресс, данные сохранения и отдельно открытия карты. Старые сохранения главы 0 и актуального сценария `chapter_1_v3/` переносятся один раз; исходные данные остаются для восстановления. Отброшенные версии главы 1 не запускаются. Игра автоматически сохраняет текущую основную сцену; кнопка сохранения фиксирует её повторно. Техническая архитектура и пример добавления будущего выбора — [STORY_STATE_ARCHITECTURE.md](STORY_STATE_ARCHITECTURE.md). Полный отчёт о проверках — [docs/CANON_SYSTEM_IMPLEMENTATION_REPORT.md](docs/CANON_SYSTEM_IMPLEMENTATION_REPORT.md).

После финального кадра сохраняется переход к будущей главе 2 **«Не тот монстр»**: выбранное существо, все четыре решения, доверие, флаги и предметы. Последнее решение задаёт начало ближе к предполагаемому логову, возможность дополнительного предмета или бонус к уликам. Это подготовленные данные продолжения; сама глава 2 пока не реализована.

## Карта решений

Нажми **«Карта решений»** в меню, на экране концовки или клавишу **B** во время игры. Нажатие на узел показывает сведения и не меняет историю.

- **Мой путь** — только текущая основная история, выделенная голубым.
- **Полный режим** — все существующие решения с отдельными действиями **«Посмотреть альтернативу»** и **«Изменить основной путь»**.
- **Вся схема** — обзор доступных глав, развилок и объединений.

Альтернатива запускается во временном состоянии. Небольшой индикатор позволяет вернуться в основную историю; её выборы, отношения, предметы и прогресс защищены даже при сохранении или перезагрузке. Золотой цвет на карте обозначает альтернативный путь, серый — открытую прежде ветку, отдельная рамка — текущий узел.

Изменение основного пути требует подтверждения. Перед записью создаётся контрольная точка; зависимые эффекты пересчитываются, независимые решения сохраняются. При ошибке основной сейв остаётся прежним. Открытия игрока сохраняются отдельно и не определяют канон.

Все ветки реализованных глав видны сразу; видимость не означает, что ветка пройдена или стала каноном. Вкладка **«Настоящая история»** показывает единую доступную только для чтения линию официального прохождения через начатые главы. Действия с альтернативами доступны в «Полном режиме».

Кнопка **«Сохранить путь» / Export Save** скачивает `reverse_falls_canon_save.json` с официальным каноном, даже во время просмотра альтернативы. **Import Save** проверяет файл и после подтверждения заменяет основной путь с контрольной точкой восстановления. Передавайте свежий JSON вместе с проектом, чтобы другой разработчик видел ваши официальные решения; во время игры источником истины остаётся StoryState.

Перетаскивай схему мышью или пальцем, меняй масштаб колесом или кнопками **− / +**. Стрелки перемещают схему, Home показывает её целиком, 0 возвращает к текущему событию. **Esc** закрывает карту. Пока она открыта, чтение и автоускорение приостановлены. Интерфейс доступен на русском и английском.

## Что включено в исходную главу 0

- Глава от начала до оригинальных титров: выбор Werewolf / Wendigo / Vampire, три городских эпизода и финал Mothman.
- Семь исходных языков, включая русский. Язык выбирается в главном меню.
- Оригинальные изображения и раздельные слои головы/тела персонажей, выражения лиц, реплики и аудио.
- Печать текста, ускорение, автоматическое чтение, скрытие интерфейса, регулировка громкости, полноэкранный режим, история и сохранение в браузере.

Клик, Пробел или Enter — допечатать реплику / дальше. Ctrl — ускорить. A — авто. H — скрыть текст. Esc или правая кнопка мыши — настройки. F — полный экран. L — история. Стрелка влево — предыдущая реплика. Сохранение хранится локально в том браузере, в котором сделано; при очистке данных браузера оно исчезает. В некоторых режимах приватности сохранения недоступны.

## Проверено и ограничения

Проверки интерпретатора проходят все 21 сочетание языка и начального выбора до титров, включая все 91 связанный игровой сценарный ресурс. В Chromium проверены открытие меню, оригинальная начальная сцена, выбор, городские эпизоды, сохранение/загрузка, переход к финалу, титры и русский текст. Подробности — `VALIDATION.md`.

Это **не подтверждённая копия пиксель в пиксель**. Видеопрохождение не было просмотрено: исходный MP4 превышает лимит переноса 32 МиБ. Воссоздание опирается на данные самой игры. Движение персонажей в многолюдных сценах, эффекты Unity, части интерфейса карты/настроек и точные переходы требуют сравнения с запущенным оригиналом. Добавлены браузерные кнопки полного экрана и истории. Двоичный Unity-проект не восстановлен: исходники здесь относятся к браузерной реализации.

Сохранены ошибки исходных текстов. Например, во французской версии введения Werewolf и Wendigo совпадают с Vampire и устанавливают флаг Vampire. Неиспользуемые черновики и недоделанная проверка Mirror не превращены в новые игровые задания.

## Разработка

`story-state.js` — единая основная история, изолированные альтернативы и атомарное сохранение; `story-bridge.js` — регистрация решений, миграция и восстановление сцен; `app.js` — воспроизведение, интерфейс и звук; `campaign.js` — выбор глав и прогресс; `flowchart.js` — графы решений и открытые ветки; `flowchart-view.js` — отображение и управление схемой; `flow-jump.js` — восстановление начала выбранной сцены через настоящее прохождение; `chapter-audio.js` — записанная озвучка, звуки и запасной Web Speech; `assets/voices/manifest.json` — соответствие реплик и MP3; `engine.js` — интерпретатор исходных сценариев; `bitmap-font.js` — исходные атласы шрифтов; `assets/scripts.json` — исходные сценарии главы 0; `assets/chapter1-scripts.json` — собранные сценарии новой главы 1; `tools/build-chapter1.py` — компиляция полного ТЗ; `tools/chapter1-english.json` — полный перевод; `assets/config.json` — данные персонажей и сцен; `assets/manifest.json` — файлы ресурсов.

При наличии Node.js и Python 3: `npm ci`, затем `npm test` и `npm run build`. Для новой главы 1 источник текста — каноническое ТЗ в `docs/CHAPTER1_REWRITE.md`, перевод — `tools/chapter1-english.json`, постановка — `tools/build-chapter1.py`. После намеренного изменения источника выполни `python3 tools/build-chapter1.py`, затем `npm run build`. Генератор проверяет наличие перевода каждого абзаца. Исходные JSON главы 0 не переписываются. Для обычной игры сборка не требуется.

Авторы оригинала указаны в игровых титрах. Подтверждённые публичные ссылки на проект и разработчика собраны в `RESEARCH.md`; более поздний веб-релиз не подменяет присланную пользователем сборку. Статус прекращения разработки независимо не подтверждён.

## Подготовка озвучки

Готовые записи главы 0 включены в ZIP; для игры модели и Python-пакеты не нужны. Источники прежнего голосового пакета и карточки моделей сохранены в `tools/voice-sources.json`. Эти записи не считаются финальной озвучкой новой главы 1.

Новая глава использует список незаполненных слотов для качественных актёрских записей. Гидеон должен звучать как спокойный мальчик 12 лет, Пасифика — как энергичная девочка-подросток 14 лет; взрослые — как взрослые. Для каждой реплики нужны осмысленные паузы, темп и эмоция. До появления подходящих записей сцена остаётся без голоса. Инструменты генерации старого голосового пакета не должны автоматически заполнять эти слоты синтетической озвучкой.
