В ZIP включены глава 4, обновления существующих систем, новый фон и спрайт вендиго, а также 36 выбранных голосовых образцов. Полная запись реплик главы 4 пока не создана. Подробности находятся в `ПРОЧТИ_МЕНЯ_ГЛАВА4.txt` внутри ZIP.
